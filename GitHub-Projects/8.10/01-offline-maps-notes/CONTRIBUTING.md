# Contributing to GeoNotes

First off, thanks for taking the time to contribute!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/{user}/01-offline-maps-notes.git`
3. Install dependencies: `npm install`
4. Create a branch: `git checkout -b feature/your-feature`
5. Make changes and run tests: `npm test`
6. Commit with conventional commits: `git commit -m "feat: add X"`
7. Push and open a PR

## Code Style

- Use TypeScript strictly
- Follow existing naming conventions
- Add tests for new features
- Run `npm run coverage` before submitting

## Reporting Issues

- Use the GitHub issue tracker
- Include steps to reproduce
- Mention browser/environment details
